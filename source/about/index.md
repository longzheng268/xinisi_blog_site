## 关于本站

辛巳学习日志网，记录技术学习笔记与日常折腾。

基于 [Hexo](https://hexo.io/) + [Butterfly](https://butterfly.js.org/) 主题搭建，博客网站部署在腾讯云 [EdgeOne](https://edgeone.ai/)，博客所用Twikoo评论部署在cloudflare。

## 技术栈

| 组件 | 技术方案                                                                                |
| ---- | --------------------------------------------------------------------------------------- |
| 框架 | [Hexo](https://hexo.io/) 8.x                                                            |
| 主题 | [Butterfly](https://butterfly.js.org/) 5.x                                              |
| 评论 | [Twikoo](https://github.com/twikoojs/twikoo-cloudflare)（Cloudflare Workers + D1 + R2） |
| 搜索 | hexo-generator-searchdb（本地搜索）                                                     |
| 公式 | KaTeX                                                                                   |
| 统计 | Busuanzi 不蒜子                                                                         |
| 部署 | 腾讯云 EdgeOne Pages                                                                    |
