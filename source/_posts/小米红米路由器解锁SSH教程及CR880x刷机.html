红米 AX3000 闲置许久，最近发现 XMiR-Patcher 已可一键开启 SSH；并且无需拆机就能在线刷入 OpenWrt。下文提供更清晰的版式、统一的图片尺寸、可复制的命令块，方便你在 WordPress 文章中直接使用。

⚠️ 刷机风险提示 操作存在变砖风险，务必确认机型、固件与分区信息一致，自行承担风险；重要数据请先备份。

第一步：解锁 SSH

XMiR-Patcher 是小米/红米路由器的补丁工具，支持开启 SSH。适配机型较多（如 CR880X 系列、红米 AX5400 电竞版、AC2100、小米万兆、AX3000T 等），大致 2023 年以前的机型成功率较高。

GitHub：XMiR-Patcher → 蓝凑云网盘镜像（可选，提取码：5lu4） →

Windows 下解压后运行 run.bat，确认默认 IP 为路由器地址，选择 2，输入 Web 后台密码，约 3 分钟即可完成解锁。默认 SSH 账户/密码：root / root。

提示：若继续使用官方固件（保持米家功能），仅开启 SSH 也可满足进阶需求。

第二步：在线刷入 OpenWrt

可选择是否先刷入大分区 U-Boot（来自 qaqal），区别在于软件可用空间：大分区约 80 MB，默认小分区约 18 MB。根据自身需求决定。

（可选）刷入大分区 U-Boot —— 展开查看命令
重要：执行写分区前确认机型与分区号完全匹配；建议逐条粘贴执行。
scp "C:\Users\你的用户名\Downloads\MIBIB.bin" root@192.168.31.1:/tmp/
scp "C:\Users\你的用户名\Downloads\APPSBL.bin" root@192.168.31.1:/tmp/
scp "C:\Users\你的用户名\Downloads\APPSBL1.bin" root@192.168.31.1:/tmp/

mtd write /tmp/MIBIB.bin /dev/mtd1
mtd write /tmp/APPSBL.bin /dev/mtd11
mtd write /tmp/APPSBL1.bin /dev/mtd12
# 完成后先不要重启，继续刷入 OpenWrt

AX3000 固件项目地址：

GitHub：openwrt-redmi-ax3000 → 蓝凑云网盘镜像（可选，提取码：5lu4） →

SSH 软刷（双系统槽位）

  1. 登录路由器 SSH，进入临时目录并下载最新工厂镜像（必须确认下载下来了，否则会成砖）： 
    cd /tmp
wget https://github.com/hzyitc/openwrt-redmi-ax3000/releases/latest/download/openwrt-ipq50xx-arm-redmi_ax3000-squashfs-nand-factory.ubi
  2. 查看分区表，确认 rootfs 与 rootfs_1 对应的 mtd 号为 mtd18/mtd19： 
    cat /proc/mtd
[[ "$(grep '"rootfs"' /proc/mtd | cut -d':' -f1)" == "mtd18" ]] || exit
[[ "$(grep '"rootfs_1"' /proc/mtd | cut -d':' -f1)" == "mtd19" ]] || exit
  3. 检测当前系统槽位，并将镜像刷到另一个槽位： 
    cat /proc/cmdline
mtd="$(grep -oE 'ubi.mtd=[a-zA-Z0-9\-\_]*' /proc/cmdline | cut -d'=' -f2)"
if [[ "$mtd" == "rootfs" ]]; then
  # 刷到 system 2
  ubiformat /dev/mtd19 -f openwrt-ipq50xx-arm-redmi_ax3000-squashfs-nand-factory.ubi
  nvram set flag_try_sys2_failed=0
  nvram set flag_boot_rootfs=1
  nvram set flag_last_success=1
  nvram commit
elif [[ "$mtd" == "rootfs_1" ]]; then
  # 刷到 system 1
  ubiformat /dev/mtd18 -f openwrt-ipq50xx-arm-redmi_ax3000-squashfs-nand-factory.ubi
  nvram set flag_try_sys1_failed=0
  nvram set flag_boot_rootfs=0
  nvram set flag_last_success=0
  nvram commit
fi
  4. 重启： 
    reboot

等待重启完成后，访问 http://192.168.1.1，用户名 root，默认密码为空。

进入 U-Boot Web：若前面刷过大分区 U-Boot，可断电按住 Reset 通电约 10 秒，浏览器访问 192.168.10.1 进入 U-Boot 页面进行后续升级/回退。
